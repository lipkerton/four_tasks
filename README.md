## Что это? ##
Это четыре задания из тестового задания.
Для каждого задания есть папка, а внутри тестовые материалы и сам код.
Для каждого файла с кодом есть аннотация, которая описывает задание.

## Особенности ##
- Использованы стандартные модули Python: sys, pathlib, itertools, json.
- Реализовано чтение json и обычных текстовых файлов.
- Реализованы разные алгоритмы.
